# Оксана — мастер красоты

Обновлённый статический сайт. Основные файлы: `index.html`, `style.css`, `app.js`, папка `assets`.

## Опубликовать через GitHub Pages

1. На GitHub нажмите **New repository** и создайте репозиторий, например `oksana-site`. Для показа клиенту выберите **Public**.
2. Распакуйте архив. В репозитории выберите **Add file → Upload files** и загрузите содержимое архива (файлы и папку `assets`, не сам ZIP). Нажмите **Commit changes**.
3. Перейдите в **Settings → Pages**. В **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/(root)**, затем нажмите **Save**.
4. После публикации GitHub покажет адрес сайта вида `https://ВАШ-ЛОГИН.github.io/oksana-site/`.

Чтобы обновить сайт позже, загрузите изменённые файлы и подтвердите коммит.
